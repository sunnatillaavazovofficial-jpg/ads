# Dock Panel

Windows uchun **taskbar o'rnida turadigan shaffof dok-panel**. Fonda ishlaydi va kompyuter yonganda o'zi ishga tushadi.

**Yuklab olish:** https://github.com/sunnatillaavazovofficial-jpg/ads/releases/latest/download/Dock-Panel.exe

## Imkoniyatlar

- **Faqat tepada:** asosiy ekranning yuqori markazida turadi. Ikonkalar standart holatda **24 px**.
- **Tepaga kirib ketish (AI Yordamchi kabi):** ochilganda bir marta ko'rinadi, keyin tepaga kirib ketadi va o'rnida **ingichka shaffof chiziq** qoladi. Kursorni chiziqqa olib borsangiz (yoki fayl sudrab kelsangiz), panel chiqib keladi; kursor ketgach yana yashirinadi. Buni Sozlamalarda o'chirsa bo'ladi.
- **O'lcham:** 20–96 px. Sozlamalarda surgich va tayyor o'lchamlar (24 / 32 / 48 / 64) bor; panel ustida **Ctrl + g'ildirakcha**; o'ng tugma menyusida (O'lcham) ham bor.
- **Fon rangi Windows mavzusiga qarab:** "Avto" rejimda Windows och yoki to'q mavzusiga qarab o'zgaradi, "taskbarda asosiy rang" yoqilgan bo'lsa, o'sha rang olinadi. Xohlasangiz, doim "Och" yoki "To'q" qilib qo'yasiz.
- **Shaffof:** foydalanilmaganda panel deyarli ko'rinmaydi. Kursor kelganda ikonkalar biroz kattalashib chiqadi; kursor qaysi ikonka ustida bo'lsa, o'sha eng ko'p chiqadi. Nom faqat kursor borganda ko'rinadi.
- **Sudrab qo'shish:** fayl, dastur, yorliq (`.lnk`) yoki papkani sichqoncha bilan panelga sudrab tashlasangiz, yorliq qo'shiladi. Ikonkalarni sudrab tartibini o'zgartirasiz; paneldan tashqariga sudrab tashlasangiz, olib tashlanadi (faylning o'zi o'chmaydi).
- **Papkalar:** papka ikonkasini bossangiz, ichidagilar oynada ochiladi (eng yangilari birinchi):
  - faylni bossangiz ochiladi, sudrab istalgan joyga (ish stoli, Telegram, Explorer…) olib borasiz;
  - fayllarni papka oynasiga yoki paneldagi papka ikonkasiga sudrab tashlasangiz, **nusxalanadi** (`Shift` bosib tursangiz, **ko'chiriladi**).
- **Dastur ikonkasi ustiga** fayl tashlasangiz, fayl o'sha dasturda ochiladi.
- **Dock papkasi:** Sozlamalarda istalgan papkani tanlaysiz (standart: Yuklanmalar). U panelning o'ng chetida, ajratuvchi chiziqdan keyin turadi.
- O'ng tugma menyusi: ochish, joylashgan papkani ochish, paneldan olib tashlash, fayl yoki papka qo'shish, sozlamalar, chiqish.
